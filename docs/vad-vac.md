# VAD / VAC 任務規格

VAD：以圖卡呈現影片到練習的工作流程。VAC：把同一任務寫成可交接、可驗收的規格。這份是工作流規格，沒有新增自動化引擎。

| 項目 | 規格 |
|---|---|
| 目標 | 提出一項有影格依據的優先改善重點 |
| 輸入 | 單次動作影片、球桿、機位、慣用手、目標、自述結果 |
| 工具 | Python、MediaPipe、OpenCV；ffmpeg 備援；能看圖的 Agent |
| 流程 | 前處理、分類複核、關鍵影格複核、資訊解讀、練習與複拍 |
| 輸出 | 拼圖、JSON、證據表、練習步驟、四週安排、未知清單 |
| 驗收 | 每項觀察可追溯；數據來源明確；假設與事實分開；複拍條件具體 |
| 停止條件 | 影片無法讀取、缺骨架、事件錯亂或資訊不足，改人工流程 |
| 人工決策 | 教練複核原因與練習適用性；球員記錄實際結果 |
| 資料界線 | 不公開原始影片；不由影像推論醫療狀態 |
