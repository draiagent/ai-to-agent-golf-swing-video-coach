# AI 影片高爾夫教練｜把每一次揮桿，變成有方向的練習

你有沒有這種經驗？練習場打了一百顆球，偶爾一球又直又遠，卻說不清楚做對了什麼；下一球失誤，又開始猜：站姿不對？上桿太快？還是手腕出了問題？

**如果練習缺少觀察與驗證，打得多，也可能只是重複同一個習慣。**

「AI 影片高爾夫教練」將手機拍攝的動作，轉成可以檢視的影格、可比較的資訊，以及下一次練習能執行的改善方向。

技能名稱：**ai-to-agent-golf-swing-video-coach**

## 一支影片，如何變成教練建議？

**影片輸入 → 姿態追蹤 → 關鍵影格 → 量化複核 → 教練判讀 → 練習追蹤。**

程式與 MediaPipe 協助追蹤身體關鍵點，依手腕位移找出候選動作位置，產生拼圖與部分時間、角度資訊。大模型再結合影格、球桿類型與目標，整理可能原因和練習建議。腳本目前不會直接產生完整教練報告，仍需要能看圖的 Agent 接續處理。

就像教練先看慢動作重播，再決定這次要練什麼。重點是建立循環：**看見問題、提出假設、安排練習、重新驗證。**

## 使用方式：四個步驟開始

**① 拍攝完整動作**

固定手機，讓全身、雙手與球桿盡量完整入鏡，保留準備到收桿的過程。可拍正面或沿目標線後方視角，光線充足、避免遮擋。每段影片先以一個完整動作為主。

**② 補充球桿與目標**

提供球桿、慣用手、拍攝角度，以及最想改善的一件事。例如：「七號鐵擊球不穩，希望找出值得練習的動作重點。」若有球路或擊球結果，也一起補充，並與影像觀察分開記錄。

**③ 交給能執行技能的 Agent**

在已配置技能、工具與執行環境的 Agent 中提供影片。單純貼上技能名稱，不代表所有聊天平台都能自動執行。先跑前處理，再讓 Agent 核對影格與 JSON；遇到看不清楚或程式失敗，要改用人工影格檢視。

**④ 帶著一個重點去練，再複拍**

一次優先練一項，後續使用相同機位與球桿重拍，比較動作是否改變，以及實際擊球表現是否更穩定。

以下三個案例為**模擬使用情境**，說明任務怎麼下、結果怎麼用，並非實際測試成果。

## 案例一｜木桿：先看動作是否一致

情境：一號木有時打得順，有時感覺下桿很急，希望了解自己的節奏。

提示詞：「請分析這段一號木影片，先確認關鍵影格，觀察上桿到下桿的節奏與身體位置。選出一個優先改善重點，提供練習方式與複拍驗收條件。」

預期產出包括上桿頂點、下桿與擊球附近影格，以及一項待驗證的動作假設。若影像支持「轉換階段不一致」，可提出降低揮桿強度、練習連貫節奏的方式，再比較數次揮桿。

影片沒有呈現的桿頭速度、距離與球路，不應自行補出數字；一號木與球道木也不能套用同一套擊球要求。

## 案例二｜鐵桿：先找可觀察的差異

情境：七號鐵偶爾打厚、偶爾打薄，希望找到值得優先檢查的動作。

提示詞：「這是七號鐵正面與後方影片，打厚打薄是我的自述。請分開列出影像觀察與可能原因，檢查擊球附近的身體位置，安排一項練習。」

預期產出包括準備姿勢與擊球附近的比較、可見的位置變化，以及仍需補拍確認的部分。如果影像顯示明顯變化，可以先列為觀察重點，安排慢速或縮小幅度的練習。

驗收時同時記錄動作與擊球結果，避免只因姿勢看起來不同，就宣布問題解決。**身體關鍵點不能直接證明桿面角度或击球最低點，原因仍需交叉驗證。**

## 案例三｜推桿：把距離感拆成可練的小任務

情境：相近距離的推桿，一下太短、一下太長，想檢查動作一致性。

提示詞：「請按推桿模式分析正面影片，複核動作分類，觀察後擺與前送的時間、幅度及手腕移動。提供一項練習，說明還需另外記錄哪些結果。」

預期產出包括候選動作影格、可辨識的節奏與擺幅資訊，以及固定條件下的重複練習。實際數值要先核對事件是否抓對；前送短不能直接證明擊球減速。

練習者另記錄每次球停的位置，再與影片比較，逐步了解動作變化是否與距離控制有關。若沒拍到完整滾動，不推算果嶺速度，也不宣稱掌握距離控制能力。

## 四週如何安排？

第 1 週建立拍攝與動作基準；第 2 週練單一重點；第 3 週整合到完整動作；第 4 週複拍、比較、調整。

四週是一個追蹤架構，實際練習量依個人能力安排。每次回顧都問：**改了什麼？證據在哪裡？下一次要保留還是調整？**
