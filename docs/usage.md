# 使用指南

版本 3.1.0｜2026-09-27

1. 準備固定手機拍攝的單次短片；全身、手與球桿入鏡。正面與沿目標線後方分别拍攝。推桿優先正面。
2. 開頭至少保留約半秒安靜站姿，因脚本用它估計初始手位置；保留完整收桿。多人、連續多球、剪接、變焦與移動鏡頭不適合直接比較。
3. 使用 README 的虛擬環境與命令。不要把真實學員影片提交到 GitHub。
4. 認真核對五個位置。候選位置可能錯序、重複或抓到另一段動作，必要時人工擷取影格。
5. 將拼圖、JSON、球桿與目標交給能看圖的 Agent，要求依 SKILL.md 產出報告。腳本不會自行呼叫大模型。
6. 同機位複拍，記錄實際擊球結果。影格變化不代表成績必然改善。

## 失敗處理

| 現象 | 處理 |
|---|---|
| 无法安裝 MediaPipe | 核對 Python／作業系統 wheel；以 ffmpeg 備援，不假稱姿態分析成功 |
| 沒有影格／沒有人物 | 停止本次腳本；先檢查影片可讀性與人像大小 |
| setup 幀未辨識 | 推桿 body_height 可能出錯，使用補拍或人工流程 |
| 同檔名不同路徑 | 先改成不同 basename，避免 JSON／dense 檔覆寫 |
| dense 圖少於完整動作 | 原碼最多取 30 格；分段補抓 |
| JSON 含 NaN 或候選點不合理 | 不作數值解讀，記錄失敗並改人工複核 |

原程式保留自使用者提供的 v3，包含以上待修正邊界；本版是教材與治理更新，不宣稱已修復演算法。
